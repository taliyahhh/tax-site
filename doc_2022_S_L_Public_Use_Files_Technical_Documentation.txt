Individual Unit Data File (Public Use Format)

This is an ASCII fixed length text file. It contains amount for each finance item code within each
government unit for all respondents and non-respondents in the sample. This large file can be useful
for programming and database applications.

For 2022, the file name is 2022FinEstDAT_07152026modp.txt and contains a standard 32-character
public-use format record layout. It is about 46 megabytes. Below is a detailed record layout for the
file.

Public-use Format File (State by level of estimate)

This file is an ASCII fixed length text file. It contains aggregated estimates of item codes by level of
estimate for each state.

For 2022, the file name is 22statetypepu.txt and contains a standard 35-character format record
layout. It is about 1 megabyte. Below is a detailed record layout for the file.

        Description                                            Positions     Length      Value
    1 FIPS state code                                             1-2             2 Char
    2 Level of estimate code                                       3              1 Char
    3 Item code                                                   5-7             3 Char
    4 Amount (in thousands of dollars)                           9-20            12 Num
    5 Coefficient of variation                                  23-32            10 Num
    6 Last two digits of survey year                            34-35             2 Char

State code – see “State Code Definitions” below.


                                         Level of Estimate Codes

                 Level Code                                                Description

                      1                       State and local government total

                      2                       State government total

                      3                       Local government total

                      5                       County government total

                      6                       City/municipality government total

                      7                       Township government total

                      8                       Special district government total

                      9                       School district government total
PID Directory Information File (Basic identifier information for corresponding finance survey)

government in the corresponding individual unit file in the annual finance survey.

For 2022, the file name is Fin_PID_2022.txt and contains a standard 146-character public-use format
record layout. It is about 13 megabytes. Below is a detailed record layout for the file.
