# Fee Fi Fo Fund

Live at **https://feefifo.fund**

*Where did your tax dollars go?* Type a zip code on the map, then see a collage of what the federal government, your state, and your city spent money on.

Plain HTML, CSS, and JavaScript. No build step, nothing to install.

## How it works

1. **The map.** Every dot is a US zip code (about 41,000). As you type digits, the matching zip codes light up and the map zooms in. At five digits it circles your town.
2. **The collage.** Each spending category is a loose, floating object scattered across the page (no boxes). Bigger objects mean more money. The big number is how many dollars out of every $100 went there. Tap one to compare all three levels of government.

## Files

```
index.html               the page
css/style.css            all styling (colors at the top under :root)
js/map.js                the landing map and zip typing
js/collage.js            builds and scatters the floating objects
js/app.js                page flow: map -> results, level tabs, popup
data/categories.js       the categories: name, image, color, description
data/budgets.js          the money: federal, California, and cities
data/zips.js             every US zip code with its map position (generated, don't edit by hand)
assets/cutouts/          category images (still PNGs)
assets/fonts/            Shrikhand + Archivo (both free, OFL license)
```

Good way to split the work: one person owns `css/` and `assets/`, the other owns `data/`.

## Swapping in real photo cutouts

The images in `assets/cutouts/` are **stand-ins** (Microsoft Fluent Emoji 3D, MIT license). The mood board calls for real photo cutouts, so replace them:

1. Find a photo (a bridge, a bus, a fire truck...). Good free sources: Unsplash, Pexels, Wikimedia Commons. Check the license.
2. Remove the background (Photoshop, remove.bg, or Preview on Mac) and export a **PNG with a transparent background**, about 600 to 800 px wide.
3. Save it over the old file with the same name (for example `assets/cutouts/roads.png`). Done. No code changes needed.

To use a different filename or color, edit `data/categories.js`.

### Using GIFs

The moving images in `assets/gifs/` are real-photo GIPHY stickers (credits in `assets/gifs/CREDITS.md`). To swap one, replace the file or change the `anim` field pointing at a GIF (transparent background works best), for example `anim: "assets/gifs/roads.gif"` in `data/categories.js`. The still PNG stays as the fallback for people with "reduce motion" turned on.

## Categories

The 12 main ones: roads & bridges, public transit, parks & recreation, education, housing & homelessness, emergency services, police & public safety, libraries & culture, public health, water & environment, government operations, defense & veterans.

Plus five "extra" buckets that don't fit the 12 but are too big to hide: **Social Security**, **paying off debt**, **safety net**, **savings & reserves** (cities), and **everything else**. Social Security alone is about $22 of every $100 the federal government spends, so leaving it out would make the numbers misleading.

Categories a government barely funds show in a gray "barely any money here" strip, which is its own lesson (California's General Fund spends almost nothing on transit; that money comes from gas taxes and fees).

## City data (automatic)

`data/cities/<STATE>.js` holds spending for every city, town, and village in that state. It's generated by `scripts/build-city-data.mjs`, which runs on GitHub Actions (`.github/workflows/build-data.yml`):

- on the 1st of every month,
- whenever the script changes,
- or by hand: repo > **Actions** > **Build city data** > **Run workflow**.

It pulls two public datasets:
- **California State Controller, By the Numbers** (API): all 482 California cities, fiscal 2023-24.
- **U.S. Census Bureau, 2022 Census of Governments**: every other local government in the US, fiscal 2022.

Don't edit those files by hand; change the script instead. To override one city with a newer budget, add it under `cities` in `data/budgets.js` (key `"City Name|ST"`).

## Adding a state

State budgets are typed in from each state's official report. Add one under `states` in `data/budgets.js`, keyed by the two-letter code. California and New York are done. Then add the source to `sources.html`.

## Put it on GitHub

1. github.com > **New repository** > name it (e.g. `fee-fi-fo-fund`) > Public > Create.
2. Click **uploading an existing file**, drag in everything in this folder (keep the folders), commit.
3. **Settings > Collaborators > Add people** and invite your teammate.
4. **Settings > Pages** > Source: **Deploy from a branch** > `main`, `/ (root)` > Save. In a minute or two it's live. The `CNAME` file points it at **feefifo.fund** (DNS is set in Porkbun: four GitHub A records plus a `www` CNAME to `taliyahhh.github.io`).

Working together: pull before you start, commit small changes often, and use a branch + pull request for big experiments. GitHub Desktop makes this easy if you haven't used git before.

Share a direct link to results with `?zip=95050` at the end of the URL.

## The tale's voices (Read it to me)

The tale under the map can read itself aloud. The voices are recordings made with **Kokoro**, a free voice model (Apache 2.0 license), stored in `assets/audio/`. Any line without a recording uses the device's built-in voice instead.

To record (or re-record after changing the tale's words), on a Mac:

```
conda create -n kokoro python=3.11 -y      # one time
conda activate kokoro
pip install kokoro soundfile               # one time
python scripts/make-audio.py --samples     # optional: hear voice options in voice-samples/
python scripts/make-audio.py               # record the tale
```

Then commit `assets/audio/` and push. The lines that get read are the ones marked `data-read` in `index.html`.
